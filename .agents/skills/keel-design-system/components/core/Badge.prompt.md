One-sentence what & when: a 10px word-pill for any classification — harm, mitigation class, status, coverage grade.

```jsx
<Badge tone="harm">code-execution</Badge>
<Badge tone="type" mono>gating_control</Badge>
<Badge tone="ok" numeric>92%</Badge>
```

`soft` gets a pill radius; every other tone gets a 4px hard corner. Keep enum values verbatim and lowercase.
