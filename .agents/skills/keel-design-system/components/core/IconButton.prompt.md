One-sentence what & when: a single Unicode glyph in a hover-filled hit area, for rail collapse, disclosure carets and card removal.

```jsx
<IconButton glyph="«" title="Collapse" />
<IconButton glyph="×" tone="danger" title="Remove weakness" />
```

Resting colour is `--navy-400`; hover fills `--navy-100` (or `--crimson-50` when `tone="danger"`). Use only the glyphs listed in readme.md → Iconography.
